# Personal Portfolio

A responsive personal portfolio website created as part of the **Oasis Infobyte Web Development Internship**.

## Project Overview

This portfolio website showcases my profile, technical skills, projects, and contact information in a clean and responsive layout.

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Features

- Profile/Hero section
- Personal introduction
- Technical skills section
- Projects showcase
- Contact section
- Responsive navigation
- Responsive design for desktop and mobile devices
- Interactive elements using JavaScript
- Consistent typography and visual styling

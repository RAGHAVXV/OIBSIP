# Temperature Converter

A responsive temperature converter web application created as part of the **Oasis Infobyte Web Development Internship**.

## Project Overview

This project allows users to convert temperatures between different units through a simple and user-friendly interface.

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Features

- Celsius to Fahrenheit conversion
- Fahrenheit to Celsius conversion
- Celsius to Kelvin conversion
- Kelvin to Celsius conversion
- User-friendly interface
- Instant temperature conversion
- Responsive design
- Input validation
- Clean and simple layout
